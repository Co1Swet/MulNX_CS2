# 停止游戏内 MulNX

向游戏内 WebSocket 网关发送：

```json
{"type":"System/Stop","payload":""}
```

请求通过既有消息总线通知原启动线程，复用正常清理流程停止模块、汇合工作线程并卸载游戏内 DLL。不弹确认窗口，不退出 CS2，也不删除软件文件；普通启动、`auto.yaml` 和原有手动退出行为保持不变。重复请求只通知一次。

网关回执仍只表示已入队，不表示已经停止；清理时连接会断开，断开本身也不能证明 DLL 已卸载。需要确认完成的调用方应检查同一游戏实例中的模块状态，再决定是否退出游戏。

该指令触发从渲染线程开始的退出流程（以满足D3D11线程安全），该指令不满足幂等性，请勿重复发送。该指令具备不可撤销性。
