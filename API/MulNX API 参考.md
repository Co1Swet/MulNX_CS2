# MulNX API 参考文档

## 核心原理

- MulNX 内部通过**消息总线**来传递信息，因此，外部接口实际上是和消息总线交互的

## 连接方式

- 连接：WebSocket，默认 ws://127.0.0.1:55202

## 消息格式

- MulNX 的外部网关忠实地将网络消息直接解释为MulNX内部消息并投入消息总线，故消息必须严格遵守格式
- 消息格式：JSON 文本帧 `{"type":"...","payload":"..."}`
- `type` 和 `payload` 均为字符串；无参数命令也需传入 `"payload":""`
- 仅支持单向发送指令，无数据查询或事件订阅

## 消息类型

- 可外部调用的消息类型及参数以 MulNX 的 CPP 代码中注册的参数转换器为准
- 具体支持可参考MulNX日志，会有订阅记录，然后可反查CPP部分如何理解数据，进而构造消息

## 参考

- 可以参考 js.html 示例

## 关键指令

- 通过
- type: Game/Command
- str1: 任意CS2控制台指令
- 可以远程使得本地客户端响应CS2控制台命令

## 运镜控制

播放当前运镜包中已加载的宏，`payload` 为完整宏名称：

```json
{"type":"CamMacro/Play","payload":"已有宏名称"}
```

强制清空播放队列（包括主动模式运镜），解除该调度器的视角覆盖：

```json
{"type":"CamPlay/ClearForce","payload":""}
```

返回的“已投入消息总线”仅表示命令已入队；实际播放或停止由后续更新异步执行。
