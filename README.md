# MulNX

> CS2 多功能 OB 与制作平台。

## **⚠️ 安全警告**

MulNX 涉及运行时注入、Hook 与运行时代码生成，其修改深度显著、覆盖面广泛，技术性质与游戏修改工具同类，本质上是一个 Hack。
**仅限获得授权的赛事、离线 Demo 分析、内容制作环境或其它合理合规环境使用。**
不得用于未授权在线对局、绕过反作弊、破坏公平竞技或任何违反 CS2 / Steam 服务条款、违反竞技公平精神的行为。
使用前必须阅读 [安全声明](SECURITY.md)。

---

## 这是什么

MulNX 为 CS2 赛事与内容创作提供专业级 OB、录制与制作能力。

从实时导播的相机、HUD 与视觉增强，到离线的 Demo 分析、批量录制与合辑产出，MulNX 覆盖赛事制播与内容生产的完整链路。

## 获取与安装

从 [Releases](../../releases) 下载最新的 **MulNX.7z**，解压即用。

预编译版本已知很长一段时间内，在正常使用条件下未收到被反作弊系统误判的报告。

有经验的用户可自行 clone 源码构建。**注意**：源码与自行配置的构建工具链可能存在反作弊兼容性问题，使用前请自行评估风险。
