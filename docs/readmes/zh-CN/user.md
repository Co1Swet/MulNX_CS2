## 概述

MulNX_CS2 是一款免费的 CS2 一站式工具包，融合实时 GOTV 与后期 Demo 工作流，支持各种复杂功能。

- 提供即时模式 UI 与磁盘路径管理，同一工程数据可同时用于直播调试与后期制作，显著提升内容创作与赛事 OB 效率。
- 独有 UI 与网络双接口设计：既可通过界面实时操控，也支持 WebSocket 协议与外部程序联动，满足自动化需求。
- 内置 OBS 渲染分离机制，录制或推流时自动隐藏界面元素，输出纯净游戏画面，并支持高级视角控制实现复杂镜头运动。

## 🛠️ 安装与使用

### 运行环境要求

- 《Counter-Strike 2》游戏
- Windows 10 或 Windows 11（功能正常）
- 部分情况可能需要“管理员权限”或“兼容模式”

### 快速开始

1. 运行 `CS2Injector.exe`（建议：右键 → 管理员权限运行）
2. 点击 **启动 CS2**
3. 首次使用需选择 CS2 安装目录

### 使用前准备

- 关闭所有第三方游戏平台

## 📈 版本信息

### 版本号规则

完整版本号格式：`Bx.y.zCx.y.z`（示例：`B0.2.0C0.27.0`）

- **B 版本号**：网络 API 版本，遵循语义化版本（Major.Minor.Patch）
- **C 版本号**：程序功能版本，自定义规则如下：

| 位 | 含义 | 兼容性影响 |
| ---- | ------ | ------------ |
| X | 决定性更新（范式变化、里程碑） | 可能导致部分资源文件不兼容 |
| Y | 阶段性更新（新工具加入、旧功能改变） | 可能引发部分资源文件不兼容 |
| Z | 维护性更新（Bug修复、优化、适配、功能完善） | 几乎不可能产生不兼容 |

> **简单理解**：B 号变化 → API / 开发接口有变；C 号变化 → 软件功能有更新。
