# MulNX

> CS2 多功能 OB 与制作平台。

## **⚠️ 安全警告**

MulNX 涉及运行时注入、Hook 与运行时代码生成，技术性质与游戏修改工具同类。
**仅限获得授权的赛事、离线 Demo 分析与内容制作环境使用。**
不得用于未授权在线对局、绕过反作弊、破坏公平竞技或任何违反 CS2 / Steam 服务条款的行为。
使用前必须阅读 [安全指南](SECURITY.md)。

---

## 这是什么

MulNX 面向 CS2 赛事 OB、Demo 分析与内容制作，提供相机系统、HUD、视觉增强、录制、媒体处理、扩展模块与配置管理能力。
