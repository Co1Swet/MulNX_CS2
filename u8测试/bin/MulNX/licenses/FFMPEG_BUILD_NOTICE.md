# FFmpeg 依赖构建说明

本项目的 FFmpeg 依赖构建环境（包括完整的 MSYS2 工具链、第三方依赖包缓存、包数据库及构建日志）已单独存放于专用仓库：

**<https://github.com/Co1Swet/MulNX_FFmpeg_Build>**

该仓库同时承担以下目的：

- **开源合规**：完整保留 FFmpeg 及其依赖的许可证信息与构建来源，便于审计和合规检查。该仓库已同步包含本项目的快照许可证信息。
- **用户自定制**：提供开箱即用的构建环境快照，方便用户按需调整编译参数、替换依赖或重新构建。
- **保持主仓库轻量**：避免数万个构建环境文件导致主仓库体积膨胀、克隆缓慢及推送超时。

本文件用于说明并指引至上述仓库。更多细节请参阅该仓库的 README。
