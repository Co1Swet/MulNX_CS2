### 环境要求

- **操作系统**：推荐 Windows 11 22H2 及以上。Windows 10 可用，但不保证完整体验。
- **路径兼容**：全面支持 UTF-8，可在任意 Windows 路径下运行，支持中文路径。
- **游戏平台**：运行前必须关闭所有第三方游戏平台。

### 安装与启动

1. 从 [Releases](../../../releases) 下载最新的 **MulNX.7z**，解压即用。
2. 通过 **CS2Injector.exe** 启动，点击“启动 CS2”。
3. 确认游戏以 `-insecure` 模式运行。
4. 关闭所有第三方游戏平台。
5. 详细启动约束见 [安全声明](../../SECURITY.md)。

### 常见问题

- 启动失败：检查日志、路径、依赖。
- 功能不生效：检查版本、配置、运行模式。
- 画面异常：检查渲染配置与资源文件。
- 崩溃或卡顿：保留日志，提交反馈。
